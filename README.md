# 💳 TomaBank UI

A simple mock banking dashboard built with JSP, TypeScript, and Tomcat.

## 🔗 Live Demo

Check out the static frontend demo here:  
➡️ [https://yymengduuu.github.io/TomaScript/](https://yymengduuu.github.io/TomaScript/)

> ⚠️ This demo only reflects static frontend behavior. Full functionality requires local deployment on Tomcat.

## 📂 Local Access

To run the project locally:  
➡️ http://localhost:8080/TomaBankUI/

## ✨ Features

- Input form for account holder name and balance
- Real-time DOM updates (no page refresh)
- Simple and responsive card-style layout

## 🚀 Getting Started

1. Start your Apache Tomcat server.
2. Deploy the `TomaBankUI.war` file to the `webapps/` directory.
3. Open your browser and navigate to:  
   `http://localhost:8080/TomaBankUI/dashboard.jsp`

## 🛠 Tech Stack

- HTML / CSS / JavaScript
- TypeScript
- JSP (JavaServer Pages)
- Apache Tomcat
