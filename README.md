# 💳 TomaBank UI

A simple JSP + JavaScript front-end mock dashboard for a bank account.

## 🔗 Live Demo

View the live version of the UI here:  
➡️ [https://yymengduuu.github.io/TomaScript/](https://yymengduuu.github.io/TomaScript/)

> Note: The live demo only reflects static frontend behavior. Full dynamic functionality requires local Tomcat deployment.

## Access the project at:
➡️ （http://localhost:8080/TomaBankUI/）

## Features

- Input form for account holder and balance
- Dynamic DOM update without page refresh
- Styled UI card layout

## Usage

1. Start your Tomcat server.
2. Deploy the `TomaBankUI.war` to the `webapps/` directory.
3. Visit `http://localhost:8080/TomaBankUI/dashboard.jsp`.

## Tech Stack
-	HTML / CSS / JavaScript
- TypeScript
-	JSP (Java Server Pages)
-	Apache Tomcat
